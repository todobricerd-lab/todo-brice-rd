# todo-brice-rd Sitio web de Todo Brice RD (Santo Domingo Este) — tienda de conveniencia con línea propia de productos de limpieza Brice. HTML + Tailwind sin build step, desplegado en Cloudflare Pages. Incluye cotizador de precios, módulo de recargas y pago de servicios, mapa de ubicación y modo claro/oscuro. Repo privado del cliente.
